# 準備
## 1.PythonをDL(https://www.python.org/downloads/)

"Or get the standalone installer for Python 3.14.5"の"Python 3.14.5"をクリック

## 2.Pythonインストーラを実行

**2.1"Use admin privileges when installing py.exe", "Add python.exe to PATH"にチェックを入れて"Customize installation"に進む**

**2.2 次の画面で全部にチェックがついていることを確認して次に進む**

**2.3 "Download debugging symbols", "Download debug binaries(requires VS 2017 or later)"以外に全てチェックがついていることを確認して次に進む**

## 3.実行環境の整備

**3.1 Windowsマークを右クリック → "ターミナル（管理者）"を選択**

3.2 "pip install opencv-python numexpr tqdm av"と入力して実行

## 4.実行

4.1 "python "(スペース入れる)と打ってVideoStabilizer_opt.pyをターミナルにドラッグアンドドロップ

4.2 Enterを押して実行!

# 使い方

1.最初のウィンドウ内で「この色に合わせたい」という映像を選ぶ

2.次のウィンドウ内で「補正したい映像のあるフォルダ」を選ぶ

3.終わったら「補正したい映像のあるフォルダ」内に"output_corrected"というフォルダがあるので、その中に調整済映像ができる

4.各自のお好きに!
