# 受け入れ基準（KPI）

リリース判定用の最低限の定量基準です。評価は短尺サンプル（暗所・高彩度・グレーカード・シーン切替参照）で実施します。

## 品質

| 指標 | 合格条件 |
|------|----------|
| 参照統計との差分 | 補正後の 7D 統計 `[Y_mean, Y_std, U_mean, U_std, V_mean, V_std, S_mean]` が参照値の ±15% 以内（平均系）/ ±25% 以内（標準偏差系） |
| 破綻率 | フレーム失敗率 < 0.1%、abort 発生なし（テストセット） |
| 色レンジ | フルレンジ入力で 16–235 クリップによる白飛び・黒つぶれが目視で増えない |

## 安定性

| 指標 | 合格条件 |
|------|----------|
| バッチ完了率 | 正常入力 10 本中 10 本が最終コンテナを出力 |
| 中断復帰 | `manifest.json` により完了済みをスキップし、失敗分のみ再試行可能 |
| 音声 | `preserve_audio=true` で音声ストリームが存在する入力の 100% で音声が残る |

## 性能

| 指標 | 合格条件 |
|------|----------|
| 実時間比 | 1080p30・1 分素材を標準プリセットで実時間の 3 倍以内（開発マシン基準） |

## 検証コマンド

```bash
uv run python -m unittest discover -s tests -v
```

E2E（モック I/O）:

```bash
uv run python -m unittest tests.test_e2e -v
```

実動画での手動確認は `docs/DEVELOPMENT.md` のサンプル手順を参照してください。
